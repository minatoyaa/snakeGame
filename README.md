# 🐍 Snake Game

A classic Snake game built with React and Vanilla CSS.

---

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/react-snake-game.git
cd react-snake-game
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🛠️ Tech Stack

- React (JSX)
- Vanilla CSS
- Vite
